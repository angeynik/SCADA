# Модель объекта и конфигурация

Как описать здание, типы установок и привязку к контроллерам. Образец — [config/example](../config/example). Код — `core/modelSchema.js` (форма файлов) и `core/modelLoader.js` (взаимные проверки и сборка тегов).

## Главный принцип

Тег называется по смыслу, а не по контроллеру: `B1/AHU-17/SupplyTemp` — объект `B1`, установка `AHU-17`, параметр `SupplyTemp`. Этот идентификатор — NodeId в OPC UA, ключ архива, имя в интерфейсе. Когда установку переводят с N30 (BACnet) на ОВЕН (Modbus), меняется только блок `source` экземпляра. Идентификатор, архив, тревоги и экраны остаются прежними.

## Каталог конфигурации

Путь — `CONFIG_DIR` в `conf.env` (по умолчанию `data/config` в каталоге сервера). Рабочая конфигурация объекта в git сервера не хранится.

```
CONFIG_DIR/
  site.json            объект (здание)
  templates/*.json     типы установок — один файл на тип
  maps/*.json          карты привязки для моделей контроллеров
  instances/*.json     установки — массив в каждом файле, файлы читаются по алфавиту
```

Для начала скопируйте образец:

```bash
mkdir -p data && cp -r config/example data/config
node tools/checkModel.js          # проверка без запуска сервера
```

## site.json

```json
{ "id": "B1", "title": "Здание 1", "timezone": "Europe/Minsk" }
```

| Поле | Обязательно | Описание |
|---|---|---|
| `id` | да | Первая часть идентификатора тега, `^[A-Za-z0-9_-]{1,64}$` |
| `title` | да | Название объекта |
| `timezone` | нет | Часовой пояс IANA для расписаний и отчётов |
| `description` | нет | Описание |

## Шаблон установки (templates/*.json)

Шаблон описывает параметры (теги) одного типа установок. Привязки к контроллеру в нём нет.

```json
{
  "id": "AhuType",
  "title": "Приточно-вытяжная установка",
  "params": {
    "SupplyTemp": {
      "title": "Температура приточного воздуха",
      "dataType": "Float",
      "unit": "°C",
      "deadband": 0.1,
      "alarms": [{ "type": "lo", "limit": 12, "deadband": 1, "delayMs": 60000, "priority": 600 }]
    },
    "SupplyTempSp": { "title": "Уставка", "dataType": "Float", "access": "rw", "min": 10, "max": 30 }
  }
}
```

Имя параметра — `^[A-Za-z][A-Za-z0-9_-]{0,63}$`. Порядок параметров в файле — порядок тегов в модели.

| Поле параметра | По умолчанию | Описание |
|---|---|---|
| `title` | — (обязательно) | Название |
| `dataType` | — (обязательно) | `Boolean`, `Int16`, `UInt16`, `Int32`, `UInt32`, `Float`, `Double`, `String` |
| `access` | `r` | `r` — чтение, `rw` — чтение и запись |
| `unit` | — | Единица измерения |
| `min`, `max` | — | Допустимый диапазон записи |
| `writeLevel` | `3` | Уровень доступа для записи: 2 — оператор, 3 — инженер, 4 — администратор |
| `states` | — | Названия значений числового параметра: `{ "0": "Стоп", "1": "Работа" }` |
| `deadband` | `0` | Мёртвая зона: изменение меньше неё не публикуется |
| `archive` | `{ "mode": "change" }` | `mode`: `change` — по изменению (мёртвая зона `archive.deadband`, по умолчанию `deadband`), `interval` — раз в `periodMs` (1 000–86 400 000 мс, обязательно), `none` — не архивировать |
| `alarms` | `[]` | Тревоги, см. ниже |
| `description` | — | Описание |

**Тревога:**

| Поле | Описание |
|---|---|
| `type` | `hi`, `lo`, `hihi`, `lolo` — предел (только числовые параметры); `state` — значение; `bad` — нет достоверных данных |
| `limit` | Предел — обязателен для `hi`/`lo`/`hihi`/`lolo`, для остальных запрещён |
| `value` | Значение для `state` — обязательно; `true`/`false` для `Boolean`, число для числовых |
| `priority` | 1–1000: 1–250 информация, 251–500 предупреждение, 501–800 авария, 801–1000 критическая |
| `deadband` | Гистерезис возврата (по умолчанию 0) |
| `delayMs` | Задержка срабатывания, 0–3 600 000 мс (по умолчанию 0) |
| `message` | Текст тревоги |

**Методы** (`methods`, необязательно) — именованные команды установки: метод OPC UA и кнопка интерфейса. Метод записывает заданное значение в параметр `rw` через тот же путь записи, что и обычная запись (права — `writeLevel` параметра, журнал).

```json
"methods": {
  "Start": { "title": "Пуск", "param": "Command", "value": true },
  "Stop":  { "title": "Стоп", "param": "Command", "value": false }
}
```

| Поле метода | Описание |
|---|---|
| `title` | Название (обязательно) |
| `param` | Параметр шаблона с `access: "rw"` (обязательно) |
| `value` | Записываемое значение: `true`/`false` для `Boolean`, число для числовых (обязательно) |

Имя метода — как у параметра и не совпадает ни с одним параметром шаблона: у них общее пространство NodeId установки (`B1/AHU-17/Start`). Если параметр исключён у экземпляра (`exclude`), метода у этой установки нет.

## Карта привязки (maps/*.json)

Карта связывает параметры шаблона с точками контроллера одной модели (одной программы). Все установки на ОВЕН с одной программой используют одну карту.

```json
{
  "id": "owen-ahu-v1",
  "driver": "modbus",
  "template": "AhuType",
  "byteOrder": "CDAB",
  "points": {
    "Command":    { "area": "coil", "address": 0 },
    "Alarm":      { "area": "holding", "address": 12, "bit": 0 },
    "SupplyTemp": { "area": "holding", "address": 100, "type": "float32" },
    "HeaterValve":{ "area": "holding", "address": 120, "type": "int16", "scale": 0.1 }
  }
}
```

Поля: `id`, `driver` (`modbus` | `bacnet`), `template`, `points`; для Modbus — `byteOrder` (`ABCD` по умолчанию, `CDAB`, `BADC`, `DCBA`); необязательно `title`, `description`. Карта может описывать не все параметры: недостающие задаются в экземпляре.

**Точка Modbus:**

| Поле | Описание |
|---|---|
| `area` | `coil`, `discrete` (биты), `holding`, `input` (регистры) |
| `address` | Адрес 0–65535 (с нуля, как в запросе Modbus) |
| `type` | `int16`, `uint16` (по умолчанию для регистров), `int32`, `uint32`, `float32` (2 регистра); для `coil`/`discrete` — только `bool` |
| `bit` | 0–15: бит регистра, значение — `Boolean`; тип при этом не задаётся |
| `scale`, `offset` | Значение = сырое × `scale` + `offset` (по умолчанию 1 и 0) |

**Точка BACnet:**

| Поле | Описание |
|---|---|
| `objectType` | `analogInput`, `analogOutput`, `analogValue`, `binaryInput`, `binaryOutput`, `binaryValue`, `multiStateInput`, `multiStateOutput`, `multiStateValue`, `characterstringValue` |
| `instance` | Номер объекта 0–4194302 |
| `priority` | Приоритет записи 8–16 (по умолчанию — из настроек драйвера, 8). Приоритеты 1–7 запрещены |
| `scale`, `offset` | Значение = presentValue × `scale` + `offset` (по умолчанию 1 и 0) |

Состояния `multiState*` в BACnet нумеруются с 1. Если в шаблоне состояния с 0, у точки задаётся `"offset": -1`: тогда номер состояния в теге одинаков для N30 и ОВЕН. Подробности о драйвере — [bacnet.md](bacnet.md).

**Совместимость параметра и точки** (проверяет загрузчик):
- `Boolean` — только `coil`, `discrete`, бит регистра или `binary*`;
- числовые типы — регистры, `analog*`, `multiState*`;
- `String` — только `characterstringValue` (в Modbus не поддерживается);
- `access: rw` нельзя привязать к `input`, `discrete` и объектам `*Input`.

## Экземпляр установки (instances/*.json)

```json
[
  {
    "id": "AHU-02",
    "title": "П2/В2 Столовая, 1 этаж",
    "template": "AhuType",
    "source": { "driver": "modbus", "map": "owen-ahu-v1", "host": "10.10.1.12", "unitId": 1 },
    "exclude": ["Humidity"],
    "params": { "SupplyTempSp": { "min": 16, "max": 24 } }
  }
]
```

| Поле | По умолчанию | Описание |
|---|---|---|
| `id` | — (обязательно) | Вторая часть идентификатора тега, `^[A-Za-z0-9_-]{1,64}$`, уникален в объекте |
| `title` | — (обязательно) | Название установки |
| `template` | — (обязательно) | Шаблон |
| `source` | — (обязательно) | Контроллер и привязка, см. ниже |
| `enabled` | `true` | `false` — установка не загружается (без ошибки) |
| `exclude` | `[]` | Параметры шаблона, которых у этой установки нет |
| `params` | `{}` | Переопределения параметров: `title`, `description`, `min`, `max`, `writeLevel`, `deadband`, `archive` (поля сливаются), `alarms` (список заменяется целиком) |

**source для Modbus:** `driver: "modbus"`, `map` (обязательно), `host` (IP или имя), `port` (502), `unitId` (1), `byteOrder` (по умолчанию из карты), `points` (свои точки — переопределяют и дополняют карту).

**source для BACnet:** `driver: "bacnet"`, `device` (номер устройства, обязательно), `address` (`IP` или `IP:порт`; без адреса устройство ищется по номеру), `map` (необязательно), `points`. На N30 номера объектов обычно у каждой установки свои, поэтому точки чаще задаются в экземпляре, а в карте — только общие (например, наружная температура).

Каждый параметр шаблона, кроме исключённых, должен быть привязан — картой или точкой экземпляра.

## Как обрабатываются ошибки

| Ошибка | Что происходит |
|---|---|
| Нет `CONFIG_DIR`, нет или ошибочен `site.json` | Сервер не запускается |
| Ошибка в шаблоне | Шаблон не загружается, все его установки отключаются |
| Ошибка в карте | Карта не загружается, её установки отключаются |
| Ошибка в экземпляре | Отключается только эта установка |
| Один `id` у нескольких установок | Отключаются все копии: какая из них верная, сервер не угадывает |
| Битый JSON | Ошибка файла, остальные файлы загружаются |

Каждая ошибка пишется в лог отдельной строкой с именем файла и установкой. Перед запуском сервера конфигурацию удобно проверять командой:

```bash
node tools/checkModel.js [--config <каталог>] [--tags]
```

Она печатает сводку, установки с адресами контроллеров и все ошибки. Код выхода — 0, если ошибок нет, иначе 1.

## Импорт из таблицы (CSV)

Для 80 установок привязки удобнее вести в таблице. Образец — [config/example/instances.csv](../config/example/instances.csv).

```bash
node tools/importTags.js установки.csv --out data/config/instances/floor2.json
node tools/checkModel.js
```

Разделитель — `;` (Excel с русской локалью) или `,`, определяется по заголовку. Колонки (порядок любой): `instance`, `title`, `template`, `driver`, `map`, `host`, `port`, `unitId`, `device`, `address`, `exclude`, `param`, `point`, `scale`, `offset`.

- **Строка без `param`** описывает установку.
- **Строка с `param`** — точка этой установки. В ней заполняются только `instance`, `param`, `point`, при необходимости `scale` и `offset`.
- `exclude` — параметры через запятую или пробел.
- Дробные числа можно писать с запятой (`0,1`).

**Короткая запись точки (`point`):**

| Драйвер | Запись | Примеры |
|---|---|---|
| Modbus | `<HR\|IR\|CO\|DI>:<адрес>[.<бит>][:<I16\|U16\|I32\|U32\|F32>]` | `HR:100:F32`, `HR:12.3`, `CO:0`, `IR:30:I16` |
| BACnet | `<AI\|AO\|AV\|BI\|BO\|BV\|MI\|MO\|MV\|CSV>:<номер>[@<приоритет>]` | `AI:1701`, `AV:1701@10` |

```
instance;title;template;driver;map;host;port;unitId;device;address;exclude;param;point;scale;offset
AHU-03;П3/В3 Конференц-зал;AhuType;modbus;owen-ahu-v1;10.10.1.13;;1;;;Humidity;;;;
AHU-03;;;;;;;;;;;HeaterValve;HR:140:I16;0,1;
AHU-18;П18/В18 Цех;AhuType;bacnet;n30-ahu;;;;30001;10.10.0.30;Humidity;;;;
AHU-18;;;;;;;;;;;SupplyTemp;AI:1801;;
```

Если в таблице есть ошибки, файл не записывается, а все ошибки печатаются с номерами строк.

## Текущие значения (core/tagStore)

- Значение тега: `{ value, quality, code, sourceTs, serverTs }`. Качество `good` | `uncertain` | `bad`, код причины — `core/quality.js`.
- После запуска все теги — `bad` / `NOT_CONNECTED`, значение `null`.
- Драйвер передаёт значения через `update(id, value, { quality, code, sourceTs })`, а обрыв связи — через `setQuality(id, 'bad', 'COMM_ERROR')`. Последнее значение при этом сохраняется.
- Изменение публикуется подписчикам, если сменилось качество или код либо значение вышло за мёртвую зону от последнего опубликованного.
- Значение не того типа не принимается: тег становится `bad` / `BAD_VALUE`.

| Код | Качество | StatusCode OPC UA | Когда |
|---|---|---|---|
| `NOT_CONNECTED` | bad | BadNotConnected | Значение ещё не получено |
| `COMM_ERROR` | bad | BadCommunicationError | Нет связи с контроллером |
| `CONFIG_ERROR` | bad | BadConfigurationError | Нет такого регистра или объекта |
| `BAD_VALUE` | bad | BadTypeMismatch | Значение не того типа |
| `DEVICE_FAULT` | bad | BadDeviceFailure | Контроллер сообщает о неисправности точки |
| `STALE` | uncertain | UncertainLastUsableValue | Значение давно не обновлялось |
| `OUT_OF_SERVICE` | uncertain | UncertainSubstituteValue | Точка выведена из работы на контроллере (BACnet Out_Of_Service): значение задано вручную, а не измерено |
